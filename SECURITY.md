# Security

## Supported versions

Only the [latest release](https://github.com/abhjz/the-training-grounds/releases/latest) gets fixes. Please update before reporting.

## Checking a download

Every release lists a SHA-256 checksum for each file, and the Android APK is always signed with the same certificate. See [Check your download is genuine](README.md#-check-your-download-is-genuine). If a file doesn't match, don't install it, and tell us where you got it.

## Reporting a vulnerability

Please **don't** open a public issue for a security problem. Use GitHub's private reporting instead: **Security → Report a vulnerability** on this repository. You'll get a reply as soon as possible.
